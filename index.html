01 — Каналы связи

Telegram / Discord / iMessage

Самый сумасшедший прикол — общаться с Claude прямо из телефона, пока сессия живёт на твоём компьютере. Клод отвечает, читает файлы, пишет код — всё через Telegram.

📲
Установка плагина
/plugin install telegram@claude-plugins-official
/telegram:configure BOT_TOKEN
🚀
Запуск с каналом
claude --channels plugin:telegram@claude-plugins-official
🔐
Первый раз — пара кодов
Отправь сообщение боту → получи код → в терминале /telegram:access pair <код>
Что можно из Telegram

✔ Задавать вопросы по коду  |  ✔ Запускать задачи  |  ✔ Получать уведомления о завершении  |  ✔ CI упал? Claude пришлёт в телегу.
⚠️ Требует Bun runtime + вход через claude.ai (не API key)

02 — Автоматизация без CI/CD

Hooks — события, триггеры, shell-команды

Хуки живут в ~/.claude/settings.json и запускаются на события: SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, Notification, PreCompact, Stop.

СобытиеКогда срабатываетПример использования
SessionStartНачало/возобновление сессииИнжектить контекст из Obsidian
PreToolUseДо выполнения инструментаЗаблокировать опасные команды (rm -rf, sudo)
PostToolUseПосле успешного инструментаАвто-форматирование, запуск тестов
NotificationClaude ждёт вниманияDesktop уведомления (macOS)
// Пример: уведомление на macOS когда Claude закончил
{
  "hooks": {
    "Notification": [{
      "matcher": "",
      "hooks": [{"type": "command", "command": "osascript -e 'display notification \"Claude закончил\" with title \"Claude Code\"'"}]
    }]
  }
}
// Защита .env файлов — запрет на редактирование
PreToolUse → matcher "Edit|Write" → bash ~/.claude/hooks/protect-env.sh
// exit 2 блокирует операцию
Логика выхода хуков

Exit 0 — разрешить, stdout → в контекст Claude. Exit 2 — заблокировать. JSON вывод — структурированное управление ({"behavior": "allow"}).

03 — MCP Серверы

Подключение внешних систем через Model Context Protocol

Глобальный конфиг: ~/.claude/mcp.json (или локальный .claude/mcp.json). Расширяет Claude доступом к базам данных, GitHub, Slack, Linear и др.

🐙
GitHub MCP
Поиск по репам, создание PR, комментарии к коду
💬
Slack
Отправка сообщений, чтение каналов
🐘
PostgreSQL
Прямые SQL-запросы из чата
📊
Sentry / Linear
Мониторинг ошибок и управление задачами
// Пример mcp.json с GitHub и БД
{
  "mcpServers": {
    "github": {"type": "http", "url": "https://mcp.github.com"},
    "postgres": {"type": "stdio", "command": "node", "args": ["mcp-pg/index.js"], "env": {"DATABASE_URL": "postgres://..."}}
  }
}
04 — Slash Commands + Skills

Custom Skills: персональные команды

Скиллы живут в ~/.claude/skills/<name>/SKILL.md (глобально) или в .claude/skills/ проекта. Claude сам поймёт когда их использовать, или вызывай вручную через /deploy, /pr-review.

---
name: pr-review
description: Ревью текущего PR
context: fork   # изолированный сабагент
allowed-tools: Bash, Read
---

Diff: !`gh pr diff`
Комментарии: !`gh pr view --comments`
Сделай ревью кода, укажи на уязвимости.

Динамический контекст: конструкция !`команда` выполнит shell и подставит вывод прямо в промпт. Поддерживаются аргументы: $0, $1... при вызове /migrate Button React Vue.

Frontmatter опции

disable-model-invocation: true — только ручной вызов. model: claude-opus-4-6 — переопределить модель. context: fork — изолированный агент для сложных задач.

05 — Персистентная память

Auto-Memory: Claude запоминает между сессиями

Хранится в ~/.claude/projects/<project-id>/memory/. Автоматически сохраняет архитектурные решения, твои предпочтения ("не мокай базу"), статус проекта. Управление через /memory.

  • 🧠
    user — кто ты, как работаешь, твои инструменты
  • 📌
    project — контекст текущего репозитория
  • 💡
    feedback — что нравится, что раздражает (авто-обучение)
  • 🔗
    reference — ссылки на внешние системы, доки, API
06 — Расписание задач

Scheduled Tasks (cloud & desktop)

🔄
Loop в сессии
/loop 5m проверь статус деплоя — повтор каждые 5 минут
☁️
Cloud (Anthropic)
/schedule create "health check" --cron "0 */4 * * *" — durable, без твоей машины, интервал ≥ 1ч
💻
Desktop (macOS/Windows)
Минимальный интервал 1 минута, пока устройство включено.
# Пример: каждые 30 секунд смотреть логи
/loop 30s следи за логами ошибок в папке logs/
07 — Глобальные настройки

settings.json и keybindings

~/.claude/settings.json — модель, пермишены, env, хуки. Пример разрешений: Bash(npm *), Read(//Users/username/projects/**), Edit(**/src/**).

{
  "model": "claude-opus-4-6",
  "permissions": {
    "allow": ["Bash(npm *)", "Read(//Users/**)"],
    "deny": ["Bash(rm -rf *)"]
  }
}

Keybindings в ~/.claude/keybindings.json (создаётся через /keybindings-help). Полезные действия: chat:stash, chat:modelPicker, history:search.

Маленькие приколы

/vim — полноценный vim mode. Extended thinking: Cmd+T или слово ultrathink (Opus). /statusline — кастомная нижняя панель с git, стоимостью. Claude автоматически ищет скиллы в монорепозиториях (родительские директории).
